# Rahma's Portfolio Website

A modern, responsive portfolio website showcasing projects, skills, and professional information. Built with HTML, CSS, and vanilla JavaScript.

## 🎯 Overview

This portfolio website features:
- **Modern Design**: Gradient backgrounds and smooth animations
- **Fully Responsive**: Optimized for desktop, tablet, and mobile devices
- **Smooth Navigation**: Seamless scrolling between sections
- **Interactive Elements**: Hover effects and active navigation highlighting

## 🔧 Installation & Setup

### Local Development

1. **Clone the repository**
   ```bash
   git clone https://github.com/rahmaissa0119-sketch/Rahma-portfolio-website.git
   cd Rahma-portfolio-website
   ```

2. **Open the website**
   - Simply open `index.html` in your web browser
   - Or use a local server:
     ```bash
     # Using Python 3
     python -m http.server 8000
     
     # Using Python 2
     python -m SimpleHTTPServer 8000
     
     # Using Node.js (http-server)
     npx http-server
     ```

3. **Access in browser**
   - Open `http://localhost:8000` (or the port shown in terminal)

## 🎯 Customization Guide

### Update Personal Information

**In `index.html`:**
- Change the name "Rahma" in the hero section and logo
- Update the email in the contact section: `mailto:your.email@example.com`
- Add project details in the Projects section

**In `style.css`:**
- Modify color variables in the style rules
- Adjust font sizes and spacing as needed
- Customize the gradient background colors

### Add New Sections

1. Create a new `<section>` in `index.html`
2. Add corresponding styles in `style.css`
3. Update navigation links to include the new section

### Deploy

**GitHub Pages:**
1. Go to repository Settings
2. Scroll to "GitHub Pages"
3. Select `main` branch as source
4. Your site will be live at `https://rahmaissa0119-sketch.github.io/Rahma-portfolio-website`
